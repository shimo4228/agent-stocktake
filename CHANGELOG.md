# Changelog

All notable changes to this skill are documented here. Format loosely follows
[Keep a Changelog](https://keepachangelog.com/); the skill is versioned in its
`SKILL.md` frontmatter (`metadata.version`).

## [1.0] — initial release

First public release of `agent-stocktake`.

- Hybrid cost model: description audited as always-loaded residency (with
  aggregate word-count tracking), body audited as invocation payload.
- Seven-question binary screen + verdict pressure-test, seven verdicts
  including Improve-by-inversion for suppression instructions and Dissolve
  judged on the fresh/rich context axis.
- Extracted from the author's live harness, where it completed the stocktake
  trio (skills / rules / agents) during the Claude 4 → Claude 5 generation
  audit (2026-07).
